# LDI
LDI laboratório de design da informação, se dedica à compreensão, conversão de dados numéricos ou qualitativos em informações visuais, com vistas a possibilitar a identificação de padrões que sejam comunicados através de diagramas.

The Information Design Lab (LDI) is dedicated to understanding and converting numerical or qualitative data into visual information, enabling the identification of patterns that are communicated through diagrams.
